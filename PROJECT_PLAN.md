# Curated by Carly

## Vision

Curated by Carly is an AI-powered luxury wardrobe concierge that helps people organize their wardrobe, dress confidently, shop intentionally, and travel effortlessly.

Inspired by the elegance, restraint, and sophistication of a Dior boutique, the experience should feel editorial rather than transactional. It will prioritize beauty, simplicity, thoughtful organization, and timeless design over feature overload.

Every interaction should support a more intentional relationship with personal style: helping users see their wardrobe clearly, dress with confidence, and make considered choices.

## Design Principles

- Quiet luxury
- White space
- Editorial photography
- Elegant typography
- Smooth, subtle animations
- Minimal but powerful interfaces
- Every clothing item should feel curated, not cataloged
- Every screen should feel like entering a Dior boutique

## Product Pillars

- Dress My Day
- My Closet
- Personal Shopper
- Packing
- Lookbooks

## Technical Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel
- GitHub
- ChatGPT Codex

The architecture should follow the Vercel-first platform direction defined in `DATABASE_PLAN.md`, including Vercel Hosting, Vercel-connected Postgres, Vercel Blob Storage, and server-side intelligence.

## Development Principles

- Build reusable components.
- Keep code modular.
- Prioritize maintainability.
- Never sacrifice elegance for speed.
- Build production-quality code.
- Preserve the luxury aesthetic.

## Current Sprint

### Sprint 1

Build the navigation foundation, establish reusable components, and prepare the app for long-term growth.

The focus of this sprint is to create a durable foundation for the product experience: clarify primary routes, establish shared interface patterns, and ensure future features can be introduced without compromising performance, maintainability, or the refined visual direction.
